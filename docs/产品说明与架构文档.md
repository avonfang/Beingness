# 此刻 · Being — 产品说明与代码架构

> 版本：v6 (Apple-grade UI) · 基于 commit cca37c1  
> 平台：微信小程序 · 原生框架 (WXML / WXSS / JS)  
> 理念来源：Eckhart Tolle《当下的力量》、Michael Singer《臣服实验》《清醒地活》

---

## 一、产品概述

**此刻** 是一款情绪觉察与正念练习的微信小程序。它帮助用户在情绪内耗（焦虑、愤怒、低落、纠结）来袭时，通过结构化引导回到当下；并通过系统化的课程学习，建立长期的觉知能力。

### 核心功能矩阵

| 功能 | 入口 | 说明 |
|------|------|------|
| 情绪急救 | 首页情绪标签 → ActionSheet | 4 种情绪 × 7-8 步引导，含分支选择 |
| 呼吸练习 | 首页快捷操作 / 急救推荐 | 5 种呼吸模式，视觉计时器 |
| 此刻信箱 | 首页快捷操作 | 写信 → 情绪识别 → 自动回信 |
| 课程学习 | Tab「学习」 | 3 条路径 × 6 课 = 18 节课 |
| 练习引导 | 课程详情 → 进入练习 | 分步实践引导，完成后记录进度 |
| 情绪日志 | Tab「日志」 | 急救记录 + 信件记录按日期分组 |
| 个人报告 | Tab「个人」 | 统计概览、情绪分布、趋势、成就 |

### 变现模式

- **心意金币（❤️）**：通过练习、分享、里程碑获取
- **主题商店**：海洋主题 20❤️、森林主题 20❤️
- **此刻·陪伴**：50❤️ 或 ¥9.9/月 — 解锁高级呼吸模式 + 无限写信额度

```

├── 点击情绪标签 (焦虑/愤怒/低落/纠结)

│   └── 写一封信给自己 → 此刻信箱
├── 今日练习卡片 → 课程详情页
├── 推荐课程条 → 课程详情页
└── 右上角 ❤️ → 心意商店
    ├── 海洋主题 (20❤️)
    ├── 森林主题 (20❤️)
    └── 7天陪伴 (50❤️)
```

## 五、数据层详解

### 5.1 存储架构

全部数据存储在微信 `wx.getStorageSync / setStorageSync` 中，**无后端依赖**。

| 存储键 | 类型 | 用途 | 写入位置 |
|--------|------|------|----------|
| `pendingEntries` | Array | 急救完成记录 | emergency → saveAndExit |
| `dialogueHistory` | Array | 写信历史 | dialogue → saveLetter |
| `awakeningCoins` | Number | 金币余额 | coins.js |
| `coinLedger` | Array | 金币流水 | coins.js |
| `streakDays` | Number | 连续天数 | index → tryAutoCheckIn |
| `lastCheckInDate` | String | 签到日期 | index → tryAutoCheckIn |
| `progress_{path}` | Number | 课程已完数 | util → completeLesson |
| `lesson_{path}_{id}` | Boolean | 单课完成 | util → completeLesson |
| `savedQuotes` | Array | 收藏语句 | lesson → saveQuote |
| `isPremium` | Boolean | 订阅状态 | profile → buyPremium |
| `purchasedThemes` | Array | 已购主题 | index/profile → buyShopItem |
| `appTheme` | String | 当前主题 | 商店购买时设置 |
| `hasSeenOnboarding` | Boolean | 新手引导 | onboarding-guide |
| `moodAfterLetter` | Array | 写信后情绪 | dialogue → goBack |
| `emotionPracticeStats` | Object | 练习偏好统计 | dialogue → goPractice |
| `dailyMsgCount` / `dailyMsgDate` | Number/String | 每日写信限额 | dialogue → checkDailyLimit |

### 5.2 情绪系统

4 种核心情绪贯穿全产品：

| 情绪 | 标签 | 图标 | 急救步数 | 关联课程 |
|------|------|------|----------|----------|
| `anxiety` | 焦虑 | 😰 | 8 步 | 临在之路 L1 (回到身体) |
| `anger` | 愤怒 | 😤 | 7 步 | 臣服之路 L1 (观察内在抗拒) |
| `low` | 低落 | 😔 | 7 步 | 开放之路 L1 (感受的流动) |
| `tangled` | 纠结 | 😵‍💫 | 7 步 | 臣服之路 L2 (放手与信任) |

急救引导采用**分支选择**模式：某些步骤的 `options` 数组提供选项，用户选择后，下步文本根据选项动态切换（`resolveStep` 中的 `step.text[previousOption]`）。

### 5.3 课程系统

3 条路径 × 6 课 = 18 节课：

| 路径 | 来源 | 图标 |
|------|------|------|
| 临在之路 | 《当下的力量》Eckhart Tolle | 🌿 |
| 臣服之路 | 《臣服实验》Michael Singer | 🍂 |
| 开放之路 | 《清醒地活》Michael Singer | 💫 |

每课结构：
```js
{
  id: "p1",
  title: "你 ≠ 你的思维",
  subtitle: "认出那个在思考的「你」",
  concept: "概念正文（多段，自动拆为滑动卡片）",
  practice: "实践引导（在 practice 页分步展示）"
}
```

每日练习从 18 课中按 `dayOfYear % 18` 轮换。

### 5.4 对话引擎

`data/dialogue.js` 是一个**纯前端对话系统**，不依赖任何 API：

- **情绪检测**：基于关键词匹配（如"焦虑"→ anxiety）
- **回复池**：6 类回复（greeting / anxiety / anger / low / tangled / general / deep），每类 4-6 条
- **渐进逻辑**：短消息 → 简短回复；检测到情绪 → 对应回复；4 轮以上 → 深度回复
- **练习推荐**：基于用户历史练习统计，推荐呼吸或练习

### 5.5 金币经济

| 行为 | 收益 | 实现位置 |
|------|------|----------|
| 完成急救 | +1❤️ | emergency → saveAndExit |
| 完成呼吸 | +1❤️ | breath → giveReward |
| 分享急救 | +1❤️ | emergency → onShareAppMessage |
| 分享呼吸 | +1❤️ | breath → onShareAppMessage |
| 完成课程 | +2❤️ | util → completeLesson |
| 连续 3 天 | +5❤️ | index → tryAutoCheckIn |
| 连续 7 天 | +10❤️ | index → tryAutoCheckIn |
| 连续 30 天 | +30❤️ | index → tryAutoCheckIn |

## 六、页面详解

### 首页 (`pages/index/`)

**职责**：导航中枢、情绪入口、日常内容展示

**状态管理**：
- `onLoad` 只执行一次：初始化主题、新手引导、每日练习
- `onShow` 每次显示执行：刷新金币、连续天数、推荐、自动签到

**关键交互**：
- 情绪标签 → `onEmotionSelect` → ActionSheet（急救/写信/呼吸）
- 今日练习 → `goDailyPractice` → Premium 检查 → 课程详情
- ❤️ 图标 → `openCoinMenu` → 底部 Sheet 商店

### 急救页 (`pages/emergency/`)

**职责**：情绪急救引导

**三阶段**：
1. `phase='select'` — 情绪选择（或从首页带入 emotion 参数跳过）
2. `phase='guide'` — 分步引导（`guide-step` 组件渲染）
3. `phase='complete'` — 笔记与评分 → `saveAndExit` → `phase='done'`

**分支逻辑**：`resolveStep()` 根据上一步的选择值 (`previousOption`) 动态切换文本

### 呼吸页 (`pages/breath/`)

**职责**：呼吸练习计时器

**5 种模式**：

| 模式 | 节奏 | 备注 |
|------|------|------|
| 4-7-8 放松 | 吸 4 → 屏 7 → 呼 8 | 默认 |
| 4-4-4 平衡 | 吸 4 → 屏 4 → 呼 4 | |
| 箱式呼吸 | 吸 4 → 屏 4 → 呼 4 → 屏 4 | |
| 谐振呼吸 | 吸 5 → 呼 5 | Premium |
| 火呼吸 | 吸 2 → 屏 1 → 呼 4 → 屏 1 | Premium |

**计时实现**：`runTimer()` 使用 `setTimeout` 自校正，每次计算 drift 调整下个 tick

### 此刻信箱 (`pages/dialogue/`)

**职责**：写信 → 情绪识别 → 自动回信

**限制**：每日 5 封免费，Premium 无限

**流程**：`sendLetter()` → `detectEmotion()` → `startEmpathySequence()` → `generateReply()`

**退出时**：弹出 Mood 跟踪（好多了/差不多/还那样），更新签到

### 课程页 (`pages/learning/lesson/`)

**职责**：滑动卡片式课程阅读

**数据**：从 `data/courses.js` 加载，`lesson.concept` 按 `\n\n` 拆为多张概念卡片，最后一张是实践卡片

**功能**：
- 左右滑动切换卡片
- 底部圆点指示进度
- 长按文字收藏（`saveQuote`）
- 完成课程 -> 调用 `completeLesson()` -> +2❤️
- 进入练习 -> 存入 `practiceText` 到 Storage -> 跳转 `practice` 页

### 个人报告 (`pages/profile/`)

**职责**：数据看板

**板块**：英雄区 → 里程碑 → 统计概览 → 情绪分布 → 周趋势 → 周简报 → 成就 → 引用收藏 → 数据洞察

**数据依赖**：`report.js` 生成洞察、成就、周报

## 八、关键设计决策

1. **无后端架构** — 全部数据存本地，适合隐私敏感的心理健康场景
2. **对话引擎纯前端** — 不依赖 LLM API，基于模板树，零成本、零延迟
3. **金币体系** — 用游戏化激励练习，同时作为主题/Premium 的虚拟货币
4. **自定义 Tab Bar** — 原生 emoji 图标，无需图片资源
5. **CSS 变量主题** — 3 套主题通过覆盖 `--primary` 等 CSS 变量实现，暗黑模式同样基于 CSS
6. **分支引导** — 急救步骤支持基于选项的分支文本，而非线性流程
