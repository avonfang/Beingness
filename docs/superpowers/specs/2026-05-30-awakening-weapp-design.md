# 「此刻」— AI 觉醒导师 · 微信小程序设计规格

## 概述

基于《当下的力量》《臣服实验》《清醒地活》三本灵性觉醒书籍的核心方法论，构建一个 AI 觉醒导师微信小程序。帮助用户在情绪内耗的当下觉察自己，并通过结构化学习路径实现长期成长。

## 产品定位

> AI 觉醒导师：用户在情绪内耗时可即时求助，在平静时可系统学习，长期使用可看见可量化的觉醒进步。

三本书的方法论映射：
- **临在之路 ← 当下的力量** — 跳出思维认同，回到当下
- **臣服之路 ← 臣服实验** — 对当下说是，放下抗拒
- **开放之路 ← 清醒地活** — 释放内心能量阻塞，开放心灵

## 目标用户

刚接触灵性觉醒的新人 + 已读过相关书籍的用户，两者兼顾。新手有引导式入门路径，老手可直接进入急救模式或跳过基础课。

## AI Agent 角色设定

### 人格
温和、沉静、不评判。话不多但每句有分量。

### 核心原则
不解决问题，而是引导用户观察自己当下的体验。

### 边界（绝不做什么）
- ❌ 不给人生建议
- ❌ 不分析心理动机
- ❌ 不共情泛滥
- ✅ 只引导用户观察自身当下的体验

### 方法论映射
| 用户状态 | 引导策略 | 来源 |
|---------|---------|------|
| 烦恼/焦虑 | 定位身体感受 | 当下的力量 |
| 抗拒/纠结 | 邀请臣服此刻 | 臣服实验 |
| 能量阻塞/低落 | 开放观察，不阻塞 | 清醒地活 |

## 核心模块

### 模块一：🆘 急救模式

用户在情绪内耗的当下打开小程序，看到极简界面，一行字："现在感觉怎么样？"

**流程：**
1. 选择情绪类型：焦虑/恐惧 | 愤怒/烦躁 | 无力/低落 | 纠结/内耗
2. AI 引导式觉察（5-6 轮结构化引导，用户选方向）
3. 复盘存档（可选笔记 + 情绪恢复评分 1-5）

**话术核心链路（以焦虑为例）：**
- Step 1: 深呼吸引导，回到当下
- Step 2: 定位身体感受（胸口/腹部/喉咙/全身）
- Step 3: 根据身体部位深入探索
- Step 4: "你不是那片云——你是看云的人"（观察者觉醒）
- Step 5: 回到呼吸，完成急救
- Step 6: 记录反思

**四种情绪的话术差异：**
- 焦虑：关注身体部位感受
- 愤怒：关注能量冲动（想做什么→观察冲动）
- 低落：关注思维叙事（注意到了什么故事→回到身体）
- 纠结：关注两个声音（观察它们而不选边）

### 模块二：📚 成长模式

三本"教材"对应三条觉醒路径：

| 路径 | 核心理念 | 课程数 | 练习示例 |
|------|---------|:------:|---------|
| 临在之路 | 从思维认同中解放 | 10 | 身体扫描、观察思维、消解痛苦之身 |
| 臣服之路 | 对当下说是 | 10 | 放下偏好练习、接纳不舒适 |
| 开放之路 | 释放阻塞的能量 | 10 | 观察者练习、拆解内心声音 |

每节课 = 概念卡片 (1min) + 实践练习 (3-5min) + 反思记录。
三条路径并行开放，用户可自由选择。

### 模块三：📊 觉醒报告

数据看板展示三个核心趋势：
1. 情绪地图：过去一周/月的情绪分布
2. 恢复速度：每次急救"进入→平复"时长变化趋势
3. 觉醒进度：三条路径的学习进度 + 练习累计次数

AI 自动生成一句话洞察：
> "这个月你有 12 次情绪波动，比上月少了 4 次。平均平复时间从 35 分钟降到了 18 分钟。"

## 页面结构

四个主要页面：

### 1. 首页—「此刻」
- App 名称 + 核心入口按钮："现在感觉怎么样？"
- 底部"今日签"（每日一句灵性语录）
- 底部 Tab 导航：[日志] [学习] [我]

### 2. 日志页—情绪时间线
- 按时间倒序排列的情绪记录卡片
- 每条 = 情绪表情 + 简短标签 + "AI 引导语摘录"
- 点击展开详情

### 3. 学习页—三条觉醒路径
- 三条横向卡片，显示进度条 + 最后练习时间
- 进入后是课程列表 + 练习入口

### 4. 我的页—觉醒报告+设置
- 情绪频率趋势图 / 恢复速度趋势图
- 连续练习天数
- 设置：提醒时间、隐私控制

## 数据模型

```
User
  - openid (微信)
  - nickname / avatar
  - courseProgress: { presence: number, surrender: number, openness: number }
  - streakDays: number
  - settings: { remindTime, privacy }

MoodEntry
  - userId
  - emotionType: anxiety | anger |低落 |纠结
  - trigger: work | relationship | health | money | other
  - bodyPart: chest | belly | throat | head | whole
  - completedSteps: boolean
  - recoveryMinutes: number
  - note: string (optional)
  - rating: 1-5 (recovery score)
  - createdAt: datetime

CourseProgress
  - userId
  - path: presence | surrender | openness
  - lessonIndex: number
  - status: not_started | completed | practice_done
  - completedAt: datetime (nullable)

WeeklyReport
  - userId
  - weekStart: date
  - emotionDistribution: { anxiety: n, anger: n, ... }
  - totalSessions: number
  - avgRecoveryMinutes: number
  - vsPreviousWeek: { sessions: +/-%, recovery: +/-% }
  - insight: string
```

## 技术方案

### 前端
- 微信小程序原生框架（或 uni-app 跨端）
- 极简 UI 风格，大量留白，柔和色调
- 动画克制而有意蕴

### 后端
- 微信云开发（云数据库 + 云函数）
- 用户数据存储在云数据库中

### AI 交互方案（关键决策）
**MVP 采用内置模板树 + 分支逻辑**，而非实时调用大模型 API。

理由：
| 方案 | 优点 | 缺点 |
|------|------|------|
| 内置模板树（选择） | 毫秒级响应、免 AI 审核资质、零成本 | 灵活性稍低 |
| 实时调用大模型 | 更灵活、可个性化 | 小程序 AI 需额外资质、延迟、费用高 |

后期扩展：用户积累练习天数可兑换一次深度 AI 对话（调用大模型）。

### 话术模板架构
话术以 JSON 树结构组织：
```json
{
  "anxiety": {
    "step1": { "text": "...", "options": [...] },
    "step2": { "text": "...", "options": ["chest", "belly", "throat", "whole"] },
    "step3": { "branches": { "chest": {...}, "belly": {...} } }
  },
  "anger": { ... },
  ...
}
```

## 阶段规划

### 第一阶段：MVP（4 周）
- 急救模式：4 种情绪 × 6 步引导树，带身体部位分支
- 成长模式：每条路径前 3 节课（共 9 节）
- 日志：简单时间线列表
- 觉醒报告：周情绪分布 + 急救次数趋势
- 用户系统：微信授权登录 + 云存储

### 第二阶段：增长
- 完整 3 条路径（每条约 10 课）
- 数据洞察 AI 总结
- 连续打卡激励
- 分享功能（今日签裂变）

### 第三阶段：深度
- 自定义触发场景标签
- 情绪预警（连续异常 → 推送提醒）
- 匿名社区功能

## 成功指标

- **留存率：** 次日 40%+，7 日 20%+（对标工具类小程序）
- **急救完成率：** 70%+ 用户完成全流程
- **恢复效率：** 用户平均恢复时间呈下降趋势（产品核心价值）
- **学习完成率：** 30%+ 用户完成至少一条路径的前 3 课
